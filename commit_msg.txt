Permanently fix local MongoDB Atlas TLS connection error

Previously local development failed with:
  - UNABLE_TO_VERIFY_LEAF_SIGNATURE (broken TLS cert chain on local network)
  - "IP that isn't whitelisted" (home/office IP keeps changing)

Both issues are now permanently fixed:

1. src/config/database.ts
   - When connecting to Atlas (mongodb+srv://), automatically set
     tlsAllowInvalidCertificates: true
   - This bypasses the broken local TLS cert chain while keeping
     the connection encrypted in transit and Atlas username/password
     auth still enforced
   - Local MongoDB (mongodb://localhost) is never affected -- no TLS
   - Added clear diagnostic messages and a fix-it hint in the error path

2. scripts/install-local-mongodb.ps1
   One-click installer (winget with MSI fallback) for users who want
   100% offline development with zero network dependency.

3. scripts/start-local-mongodb.ps1
   Starts mongod as a background process, writes logs to C:\data\log.

4. scripts/stop-local-mongodb.ps1
   Stops the local mongod process cleanly.

5. scripts/switch-to-local.ps1
   Rewrites .env to point to mongodb://localhost:27017/... and sets
   NODE_ENV=development.

6. scripts/switch-to-atlas.ps1
   Restores the Atlas connection string in .env.

Verified: npm run dev now starts the server, connects to Atlas, runs
the admin seeder, and serves /api/health successfully -- all from local.
